# Java Banking System
A console-based Java application that simulates bank operations and uses custom data structures.

# What was done:
**Custom Data Structures:** Created a custom Linked List for accounts, and custom Stack and Queues for transaction history and bill payments (without using built-in Java collections).

**OOP Architecture:** Divided the logic into separate classes (BankAccount, Request, Main) to keep the code clean and modular.

**Bank Operations:** Added features to submit new account requests, deposit money, and withdraw cash with balance checks.

**ATM Operations:** Created an ATM menu where users can check their balance and withdraw money.

**Admin Panel:** Added functions to process pending account requests, manage bill payments, and view all registered users.

**Transaction History:** Used a custom Stack (MyStack) to save and print all deposit and withdrawal operations.

**Data Processing:** Used a custom Queue (MyQueue) to process bills one by one.
